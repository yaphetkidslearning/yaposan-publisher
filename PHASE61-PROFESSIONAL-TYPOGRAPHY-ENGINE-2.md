# Phase 61 - Professional Typography Engine 2

Phase 61 extends Yaposan with a nondestructive professional typography pipeline suitable for print, web, PDF, SVG, and multilingual publishing.

## Included

- Variable font axes with safe min/max normalization
- Advanced OpenType features and stylistic sets
- Script detection, bidirectional direction selection, multilingual font fallback, and Ethiopic/CJK/Arabic support
- Text on editable vector paths
- Multi-line, balanced, and single-line paragraph composers
- Professional hyphenation, justification, widow/orphan, and keep controls
- Linked text-frame threads with overset behavior and column balancing
- Optical kerning, optical sizing, hanging punctuation, and baseline grids
- Font embedding/subsetting, restricted-font outlining, tagged/searchable text, and color-glyph export controls
- Typography layout planning and preflight validation
- Phase 61 regression tests

## Validation

Run `npm run verify:phase61` after installing dependencies.
