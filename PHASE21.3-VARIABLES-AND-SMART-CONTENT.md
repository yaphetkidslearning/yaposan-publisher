# Phase 21.3 — Variables and Smart Content

Phase 21.3 adds dynamic publication fields and reusable running content to the real Yaposan editor.

## Included
- Built-in metadata, page, section, date, revision, and file variables
- Custom named variables with persistent values
- Token insertion into selected text objects
- Context-aware resolution for each page
- Running headers and footers with left/right and first-page templates
- Document-wide or section-scoped rules
- Live active-page preview
- Validation for duplicate and unknown tokens
- JSON production report export
- Save/load migration and undo/history integration
