# Phase 17.18 — Professional Image Editor

Phase 17.18 adds a native professional image-editing workspace to Yaposan.

## Included

- Docked tool rail, tool options bar, canvas, status bar and inspector panels
- Layers, groups, visibility, opacity-ready state, fill opacity and blend modes
- Duplicate, delete, merge visible and flatten workflows
- Raster and vector mask state with density, feather, invert, link and enable properties
- Adjustment layers for brightness/contrast, levels, curves, exposure, vibrance, hue/saturation, color balance, black & white, gradient map, selective color and color lookup
- Brush settings for size, hardness, opacity, flow, spacing, scatter, jitter, pressure, wetness and mix
- Selection state with feather, expand, antialias, combination mode and saved selections
- Healing, clone, patch, content-aware, red-eye, quick selection, magic wand and eyedropper tool entries
- RGB/CMYK preview, soft-proof control, histogram, channels, navigator and info panels
- Tile-rendering, cache, background-rendering, GPU-ready and large-image optimization configuration
- Local persistence through AsyncStorage
- Photo Studio launch integration

## Important boundary

Phase 17.18 provides the complete professional editor workspace, state engine and non-destructive management workflows. Real GPU kernels, native ICC conversion, advanced content-aware generation and pressure-sensitive device input still require native/provider implementations.
