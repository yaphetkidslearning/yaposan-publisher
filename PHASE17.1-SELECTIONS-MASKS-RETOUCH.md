# Phase 17.1 — Professional Selections, Masks, Crop and Retouch

Phase 17.1 extends the integrated Photo Studio with a non-destructive professional image-editing workflow.

## Included

- Rectangle, ellipse, lasso, polygon, subject and color-range saved selections
- Selection feathering, expansion/contraction and inversion
- Selection-to-mask conversion
- Mask density, feather, inversion and linked state
- Non-destructive crop rectangle, aspect presets, straighten angle and perspective crop metadata
- Adjustment-layer duplicate and reorder controls
- Healing, clone, dodge, burn and smudge retouch stroke records
- Configurable retouch brush size and strength
- Raster history snapshot restore
- Expanded image audit and document statistics
- Phase 17.1 test and verification scripts

The selection, mask, crop, retouch and history state is stored with each image element and survives project save/load.
