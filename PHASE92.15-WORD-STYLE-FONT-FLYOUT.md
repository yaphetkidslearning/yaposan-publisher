# Phase 92.15 — Word-Style Font Flyout

This update is based on the supplied **Yaposan 92.14 FINAL CORRECTED** package.

## Font dropdown correction

- The Home ribbon font family picker now opens as an anchored desktop flyout directly below the Font control area instead of as a centered modal.
- The document is no longer dimmed when the font list is open.
- The flyout uses a compact Word/Excel-like width, tighter rows, square category controls, and a denser font preview list.
- Clicking outside the flyout closes it.
- Search, categories, font previews, selected-font highlighting, and Open Font Manager are preserved.

Package version: **92.15**
