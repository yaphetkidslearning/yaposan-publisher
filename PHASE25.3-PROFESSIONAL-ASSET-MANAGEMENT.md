# Phase 25.3 — Professional Asset Management

Phase 25.3 integrates a production Digital Asset Manager into the real Yaposan editor.

## Included
- Central DAM workspace and Asset ribbon
- Linked and embedded assets with relinking
- Asset version history and restoration model
- Collections, tags, metadata, search, filters, and duplicate detection
- Font registry and missing-font validation
- Icons, templates, document, image, vector, audio, and video asset types
- Brand and stock-library architecture with license metadata
- Packaging and preflight reporting
- Backward compatibility with Phases 0–25.2

Run `npm run verify:phase25.3` after installing dependencies.
