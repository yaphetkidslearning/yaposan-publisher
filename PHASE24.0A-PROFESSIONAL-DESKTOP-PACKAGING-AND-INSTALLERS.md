# Phase 24.0A — Professional Desktop Packaging and Installers

Phase 24.0A converts the production Expo web build into a hardened Electron desktop application and provides real electron-builder targets for Windows, macOS, and Linux.

## Installer outputs

- Windows: NSIS `.exe` and Windows Installer `.msi`
- macOS: `.dmg` for Intel and Apple Silicon
- Linux: `.AppImage` and `.deb`
- Portable: compressed production web distribution

## Build commands

```powershell
npm install
npm run desktop:web
npm run desktop:build:win
npm run desktop:manifest
```

macOS installers must be generated on macOS, and public distribution requires an Apple Developer certificate and notarization credentials. Windows installers should be signed with an Authenticode certificate. Linux packages can be generated on Linux.

## Complete verification

```powershell
npm run verify:phase24.0a
```

The verification command runs the Phase 24 regression chain, desktop packaging tests, the packaging audit, a production web export, and installer-manifest generation. Actual platform installers are generated by their platform-specific `desktop:build:*` commands because cross-platform signing and native package tooling require the matching operating system.
