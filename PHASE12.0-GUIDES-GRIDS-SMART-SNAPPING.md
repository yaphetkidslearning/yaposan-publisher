# Phase 12.0 — Guides, Grids & Smart Snapping

Integrated into the real Yaposan Publisher editor.

## Added
- Document-level layout settings persisted on every page
- Horizontal and vertical custom guides with names, positions, colors, locking and visibility
- Guide Manager and Grid Manager combined professional modal
- Square, modular, column, row, baseline and composition grid modes
- Rule of Thirds, Golden Ratio, Fibonacci, diagonal and center-crosshair choices
- Safe-area, live-area and slug settings
- Smart snapping configuration for guides, grids, margins, bleed, safe areas, page edges, objects, spacing and baseline grids
- Adjustable snap tolerance
- Layout ribbon integration
- Canvas rendering for custom guides, safe area and composition overlays
- Save/load, undo/redo and export-model preservation through page data
- Phase 12.0 regression tests
