# Yaposan User Manual

## Start a project
Open the Home workspace, choose a professional template or blank format, name the project and select a destination workspace. Save creates a recoverable project version.

## Editing workflow
Use the ribbon and studio tools to add text, images, video, audio, shapes and data objects. Undo and Redo must remain available throughout the active session. Use project history to restore earlier saved versions.

## Cross-studio workflow
Assets created in Photo Studio, Video Studio, Audio Studio and Yaposan AI should be stored in the shared project library before use in Publisher, Presentation, Web or Social workspaces.

## Export
Choose the target format, quality, dimensions, background, metadata and destination. Review the validation report before publishing. Large media exports may be sent to the render queue, where progress, cancellation and retry are available.

## Accessibility
Use keyboard navigation, meaningful names, sufficient contrast, reading order, captions, alt text and reduced-motion previews before release.

## Troubleshooting
Check project sync, storage availability, provider credentials and the health dashboard. Preserve the correlation ID shown in an error when contacting support.
