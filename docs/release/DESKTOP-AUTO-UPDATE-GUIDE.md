# Phase 24.0B — Professional Auto-Update System

Phase 24.0B adds a production Electron update lifecycle to Yaposan Publisher.

## Capabilities

- Stable, beta, and development channels
- Automatic startup checks in packaged desktop builds
- Manual update checks from the Review ribbon
- User-controlled automatic download and install-on-quit policies
- Download progress, release version, release notes, and errors
- Explicit restart-and-install action
- Update policy persistence in the Electron user-data directory
- Hardened IPC bridge; the web renderer never receives Node.js access
- Generic HTTPS update feed compatible with electron-builder metadata
- Windows, macOS, and Linux publish commands

## Required deployment configuration

Set `YAPOSAN_UPDATE_URL` to the HTTPS directory that hosts the update metadata and installer files. The feed must contain the metadata generated by electron-builder, such as `latest.yml`, `latest-mac.yml`, or `latest-linux.yml`.

Public production updates must be code-signed. macOS packages must also be notarized. Update verification uses the platform signing configuration supplied by Phase 24.0A and electron-updater.

## Local verification

```powershell
npm ci
npm run verify:phase24.0b
```

## Publishing

Run each command on its matching operating system:

```powershell
npm run desktop:publish:win
```

```bash
npm run desktop:publish:mac
npm run desktop:publish:linux
```

The installed desktop application exposes **Review → Final Release → Desktop Updates**.
