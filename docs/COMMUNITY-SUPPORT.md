# Community Support

Use the right channel so requests reach the right people.

| Need | Channel |
|---|---|
| Reproducible software bug | GitHub Issues |
| Feature proposal | GitHub Discussions first; Issue when scoped |
| Development question | GitHub Discussions Q&A |
| General idea | GitHub Discussions Ideas |
| Showcase/template | GitHub Discussions Show and Tell |
| Security vulnerability | Private vulnerability reporting / SECURITY.md |
| Account, billing, hosted-service or private-data problem | Official Yaposan support, not a public issue |

Never post passwords, API keys, access tokens, private customer data, billing details, or security exploit details in public Issues or Discussions.
