# Asset and Dependency License Policy

Before adding third-party code or creative assets, verify that redistribution and intended use are permitted. Record the source, author/provider, license, and any attribution requirement. Do not commit assets copied from commercial libraries, stock sites, fonts, model repositories, or template marketplaces unless their license clearly permits repository redistribution.

Pull requests that add fonts, icons, images, audio, video, templates, AI models, datasets, or substantial third-party code should identify their provenance and license. Maintainers may reject material with unclear rights.
