# Yaposan Phase 25.1 — Professional Desktop Publishing Engine

Integrated directly into the production editor on top of Phase 25.0.

## Included
- Multi-line professional text composition and live composition metrics
- Language-aware discretionary hyphenation controls
- Optical margin alignment settings
- Configurable baseline grids and body-text snapping
- OpenType ligatures, small caps, figures, fractions, stylistic sets and kerning modes
- Widow/orphan and keep-with-next pagination controls
- Multi-column composition
- Footnotes and endnotes
- Book chapters, page numbering models and long-document structure
- Table of contents generation
- Index entry collection and index generation
- Composition preflight with loose-line and overset-risk reporting
- Dedicated Publishing ribbon and integrated professional workspace

## Validation
Run `npm run verify:phase25.1`.
