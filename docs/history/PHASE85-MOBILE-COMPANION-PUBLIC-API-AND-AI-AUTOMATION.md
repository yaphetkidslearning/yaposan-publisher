# Phase 85 — Mobile Companion, Public API, and AI Automation

This release extends Phase 84 with working foundations for mobile companion access, scoped public API keys, signed webhooks, trusted mobile devices, and scheduled AI automation.

## Included

- Mobile companion project, notification, export, comment, and approval contracts.
- Device registration, trust, and revocation service.
- Scoped API-key creation, authentication, listing, and revocation.
- Signed webhook subscriptions and HMAC delivery signatures.
- AI automation queue, scheduling metadata, cancellation, and history.
- Developer & Mobile Center web page.
- Phase 85 regression tests.

Native iOS and Android binaries still require their own build pipelines, signing credentials, and store accounts.
