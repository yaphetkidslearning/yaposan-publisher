# Phase 52 — Global Localization & Publishing Platform

Phase 52 adds a production-oriented international publishing foundation to Yaposan.

## Included

- Typed locale-pack registry with completion and activation state
- Left-to-right and right-to-left publication metadata
- Translation-memory data model and review status
- Brand terminology and glossary governance foundation
- Regional presets for dates, currency, measurements, paper sizes, and export naming
- Global-content quality checks for untranslated content and review blockers
- Persistent locale activation in the Global Publishing screen
- Evidence-based release score for enabled locales

## External requirements

Real machine translation, professional linguist networks, cloud translation memory, remote glossary synchronization, and locale-specific legal review require configured external providers and approved credentials. Phase 52 does not claim those external services are deployed.

## Validation

Run:

```bash
npm run test:phase52
```

Full TypeScript verification requires installed project dependencies.
