# Phase 25.28 — Collapsible Template Categories and Coverage Audit

Phase 25.28 updates the template browser sidebar shown in the supplied screenshots.

## Completed

- Business, Marketing, Social Media, Print, and Office are clickable accordion headings.
- Selecting a heading displays every active template matched to that category group.
- Expanding a heading reveals all of its template-type buttons.
- Selecting a template-type button filters the active library using exact names and compatibility aliases.
- Category and template-type counts are shown in the sidebar.
- Zero-count buttons remain visible so missing library coverage is easy to identify.

## Coverage behavior

The active handcrafted libraries use some newer names, including Premium Brochures, Annual Reports, Event Flyers, Labels and Packaging, Resumes and CVs, and Proposals and Media Kits. Phase 25.28 maps those names to the established sidebar categories instead of hiding them.
