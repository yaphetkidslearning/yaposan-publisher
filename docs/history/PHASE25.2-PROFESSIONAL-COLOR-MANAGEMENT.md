# Phase 25.2 — Professional Color Management

Integrated into the real Yaposan editor on top of Phase 25.1.

## Production capabilities
- ICC working, embedded, proof and output profile architecture
- RGB, CMYK, LAB, grayscale and spot-color models
- Profile-aware conversion controls and rendering intents
- Black-point compensation, preserve-black and preserve-spot policies
- CMYK ink limiting and total-area-coverage preflight
- Pantone essential spot library plus extensible custom spot libraries
- Process and spot separation plate generation
- Soft proofing with paper and black-ink simulation controls
- Ink preview, overprint preview and plate visibility controls
- Color audit scoring, issue remediation guidance and production validation
- Professional Color workspace and Color ribbon integrated into the existing editor

No standalone demo route is introduced. Phase 25.0 and Phase 25.1 remain present.
