# Phase 21.2 — Professional References and Navigation

Phase 21.2 extends the Phase 21 document production system with persistent publication references.

## Included
- Automatic table of contents from sections and Heading 1–3 styled text
- Index terms and subterms with professional page-number resolution
- Page and object bookmarks
- Footnotes and endnotes with automatic numbering
- Internal cross-references to pages, sections, bookmarks, and elements
- External URL and mail hyperlinks
- Broken-reference validation
- Direct navigation to referenced pages and objects
- Save/load migration and backward compatibility
- JSON production report export
- Undo/history integration in the real editor

## Validation
The dependency-free runtime assertions cover migration, TOC, index, bookmarks, notes, cross-reference resolution, and validation. Full project TypeScript checking still requires the project dependencies to be installed locally.
