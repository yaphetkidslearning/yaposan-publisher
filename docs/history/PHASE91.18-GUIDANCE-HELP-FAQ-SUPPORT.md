# Phase 91.18 — User Guidance, Help Center, FAQ & Support Completion

Phase 91.18 expands the 91.17 help foundation into a platform-wide guidance system.

## Added
- First-run five-step onboarding on Home with persistent dismissal.
- Searchable Help Center that searches both guides and FAQ answers.
- Dedicated `/faq` with categorized expandable Q&A (40+ answers).
- Dedicated `/troubleshoot` with guided diagnostic flows for AI, background removal, projects, export, sign-in, and web publishing.
- Live signed-in image/video/audio/background-removal readiness in Troubleshooting.
- Contextual Help button in the shared Yaposan workspace shell.
- Direct setting/studio/support links throughout guidance.
- Keyboard-shortcut documentation.
- Plain-language Yaposan glossary.
- Improved Project Library empty-state guidance.
- Photo Studio inline troubleshooting link when image AI is not configured.
- Richer Contact & Support form: name, email, category, priority, subject, description, attachment, and opt-in non-secret diagnostics.
- Contact remains honest: no ticket/email delivery is claimed until a real support destination is configured.
- `/help`, `/faq`, `/troubleshoot`, and `/contact` are public SEO routes and are included in the sitemap.

## Validation
Run `npm run verify:phase91.18` for TypeScript, Phase 91.11–91.18 regression tests, static gates, and production web export.
