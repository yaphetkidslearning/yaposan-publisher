# Phase 13.2 — Soft Proofing, Finishing & Press Handoff

Phase 13.2 extends the professional printing and prepress system with press-proof simulation, finishing specifications, dieline validation, and imposition sheet geometry.

## Included

- Composite, separation, overprint, and gamut proof modes
- Active CMYK plate preview selection
- Paper and black-ink simulation settings
- Out-of-gamut color diagnostics
- Fold, score, perforation, die-cut, foil, varnish, and emboss finishing settings
- Dieline requirement and named CutContour validation
- Dieline overprint and minimum production line-width controls
- Finishing-object detection from production object names
- Positioned imposition sheet geometry for one-up, two-up, four-up, booklet, and step-repeat modes
- Expanded production manifest with finishing and proof mode
- Six Phase 13.2 regression tests
