# Phase 14.2 — Batch Merge and Export

Integrated into the real Mailings workflow.

- Generates one resolved publication per filtered record or one combined document.
- Supports PDF, PNG, JPG, and SVG through the production Phase 9 export engine.
- Excludes duplicate records by default with an explicit include option.
- Uses current record search, filtering, and sorting.
- Supports progress reporting and cancellation.
- Saves batch settings and the latest 50 job-history records with the project.
- Produces optional export reports and configurable file names.
