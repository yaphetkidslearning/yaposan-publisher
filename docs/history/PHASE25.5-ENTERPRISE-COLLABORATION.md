# Phase 25.5 — Enterprise Collaboration

Phase 25.5 adds a production-oriented collaboration layer to the existing Yaposan editor while retaining Phases 25.0–25.4.

## Integrated capabilities
- Dedicated Collaboration ribbon and enterprise workspace
- Role-based permissions for owners, admins, designers, editors, reviewers, and viewers
- Team presence and active-page awareness
- Threaded page/element comments, mentions, replies, and resolution
- Formal review requests, approval decisions, change requests, and due dates
- Secure sharing policy with sign-in, download, copy, expiry, and watermark controls
- Workspace activity history and governance audit
- Deterministic concurrent-change merge and conflict reporting
- Server/identity-provider adapter-ready state model; no credentials stored in project files

## Verification
Run `npm install` followed by `npm run verify:phase25.5`.
