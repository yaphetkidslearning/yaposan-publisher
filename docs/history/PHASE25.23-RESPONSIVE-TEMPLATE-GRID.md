# Phase 25.23 - Responsive Template Grid

Phase 25.23 fixes the empty horizontal area visible on wide template-browser screens.

## Changes

- Template cards now calculate their width from the available browser area.
- Wide screens display additional columns instead of leaving a large blank region.
- Medium and narrow screens automatically reduce the number of columns.
- Compact grid and list layouts remain available.
- Safe back navigation from Phase 25.22 remains unchanged.

## Version

25.23.0
