# Phase 20.1 — Advanced Integration

Phase 20.1 extends the local-first collaboration and review system into a complete editor-connected workflow.

## Integrated features
- Comment search and scope filters for all pages, current page, or selected object
- Direct navigation from a review comment to its page and linked object
- Real threaded replies with activity logging
- Reviewer assignment and due dates with overdue tracking
- Reviewer/member management with roles and active/inactive state
- Approval notes and multi-reviewer approval policy
- Review lock policy and approval-required policy
- Enhanced release-readiness rules
- Version 2 portable review report with policy data
- Review report import engine with schema validation
- Phase 20.1 persistence and migration from Phase 20.0 state

No external cloud service is simulated. All features work locally and remain ready for a future authenticated synchronization layer.
