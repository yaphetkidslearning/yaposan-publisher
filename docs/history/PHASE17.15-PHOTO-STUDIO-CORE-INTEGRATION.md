# Phase 17.15 — Photo Studio Core Integration

Phase 17.15 migrates the reusable editor infrastructure from the earlier GWC Studio project into Yaposan as a native workspace.

## Included
- Multi-image import and gallery
- Image selection, reorder, and removal
- Non-destructive transform metadata
- Zoom, fit, rotate, and before/after preview
- Shared undo/redo history
- Local autosave and restore through AsyncStorage
- Shared routes to the Yaposan raster editor, asset library, and export center
- Responsive workspace and premium 3D controls

## Migration status
Core editor infrastructure is integrated. AI image services move in Phase 17.16. Commerce, listing, marketplace, automation, and analytics workflows move in Phase 17.17.
