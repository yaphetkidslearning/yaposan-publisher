# Yaposan Publisher 92.9 — Multilingual Font Expansion

Version 92.9 expands Publisher typography beyond Latin fonts.

## Added
- 70+ multilingual font-family choices in addition to the existing 142-family catalog.
- Script filters in the ribbon font dropdown and Professional Font Manager.
- Arabic/Hebrew, Ethiopic (including Amharic), Indic, CJK, Southeast Asian, Greek/Cyrillic/Vietnamese and other-script groups.
- Noto-oriented fallback strategy for multilingual text.
- Search, preview, selection, favorites, recents, and custom-font behavior remain available.

## Important runtime note
Font-family entries use installed/system fonts when available. For exact cross-device rendering, import/embed the desired TTF/OTF through Font Manager or package web-font assets with the application.
