# Third-Party Notices

Yaposan includes third-party open-source dependencies and may use third-party creative assets. Those materials remain subject to their own license terms and are not relicensed merely because Yaposan source code is distributed under MIT.

For JavaScript dependencies, run `npm run licenses:check` after `npm ci` to identify packages whose installed metadata does not expose a license field. Review dependency licenses before releases and whenever a pull request adds or changes dependencies.

For fonts, images, icons, audio, video, templates, AI models, datasets, and other creative assets, follow `docs/ASSET-LICENSE-POLICY.md`. Contributors should document source/provenance and redistribution rights in the pull request.

This file is a compliance aid, not legal advice and not a substitute for reviewing the actual license text of each dependency or asset.
