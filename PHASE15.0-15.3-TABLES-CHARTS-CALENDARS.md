# Phase 15.0–15.3 — Professional Tables, Charts and Calendars

## Phase 15.0 — Professional Table Foundation

- Spreadsheet-like editable table objects on the real publication canvas
- Insert/delete rows and columns
- Merge/split cells
- Cell padding and vertical alignment metadata
- Header and footer row metadata
- Repeat-header support for multi-page workflows
- Banded rows, professional, invoice, price-list and schedule templates
- Auto-fit, equal rows and equal columns
- Sorting, filtering, CSV/XLSX import and export through the existing table engine
- Save/load, undo/redo and export compatibility

## Phase 15.1 — Advanced Cell Formatting

- General, text, number, currency, percentage, date, time and datetime formatting
- Scientific notation and fraction formatting
- Rich cell-format metadata for font, fill, borders, alignment, wrapping and rotation
- Existing formula engine supports SUM, AVERAGE, MIN, MAX, COUNT, references and arithmetic
- Images and icons remain supported as publication objects layered with tables
- Conditional-format metadata is preserved by the table object model

## Phase 15.2 — Charts

The new chart generator creates scalable SVG-backed publication elements. Supported chart types:

- Column
- Bar
- Line
- Area
- Pie
- Doughnut
- Scatter
- Radar

Chart source data, title and type remain serialized on the element for future editing. SVG output is compatible with existing save/load, resize, rotation, PDF, PNG, JPG and SVG export paths.

## Phase 15.3 — Calendars and Schedules

- Monthly calendar generator
- Sunday or Monday week-start engine support
- Event placement by ISO date
- Weekly schedules
- Daily schedules
- Academic schedules
- Fiscal schedules
- Planner layouts
- Generated calendars are real editable table objects

## Editor integration

Open **Insert → Chart & Calendar** to launch the Phase 15 workspace. The same workspace can create professional table templates, charts, monthly calendars and schedule objects.
