# Phase 11.1 — Advanced Character Typography

Integrated into the production editor:
- manual kerning and tracking
- baseline shift, superscript and subscript
- uppercase, lowercase and small caps
- ligatures and OpenType-style controls
- underline styles and strikethrough
- variable font axes for weight, width and optical size
- reusable character style presets
- canvas rendering, save/load, undo/redo and export-compatible project data
- regression tests
