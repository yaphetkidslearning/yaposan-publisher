# Phase 25.8 — Enterprise Integration Platform

Phase 25.8 adds a governed connector and API layer to the real Yaposan editor.

## Included
- Cloud-storage, commerce, productivity, identity, analytics, and publishing connector models
- Push, pull, and bidirectional synchronization policies
- Encrypted credential requirements and least-privilege scope metadata
- Queued import, export, publish, sync, and webhook jobs
- Signed webhook subscriptions and event routing
- Retry limits, execution history, failure reporting, and connection health
- Administrator approval gates and external-connection controls
- Integration governance audit and readiness scoring
- Dedicated Integration ribbon and enterprise workspace

## Verification
Run `npm run verify:phase25.8` after installing dependencies.
