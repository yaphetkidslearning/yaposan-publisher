# Phase 14.1 — Merge Fields, Conditions and Live Preview

Integrated into the production editor on top of Phase 14.0.

## Delivered
- Non-destructive live merge preview on the real canvas
- First, previous, next and last record navigation
- Text merge fields using `{{field_name}}`
- Inline formatting: upper, lower, title, number, currency and date
- Saved per-field default values and formatting properties
- Empty-field handling
- IF / ELSE text rules
- Conditional element visibility
- Image-field binding model
- Record-aware canvas status
- Project serialization, undo and auto-save compatibility
- Editing protection while live preview is enabled

## Validation
Run `npm run verify:phase14.1`.
