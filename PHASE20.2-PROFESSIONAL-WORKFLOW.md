# Phase 20.2 — Professional Workflow

Phase 20.2 turns the collaboration workspace into a controlled publication workflow integrated directly into the real editor.

## Integrated features
- Six-stage publishing workflow: Draft, Content Review, Design Review, Preflight, Approval, Released
- Forward-stage release gates with clear blocker reasons
- Required and optional workflow tasks
- Task assignees, due dates, pending/in-progress/blocked/complete states
- Workflow progress, blocked-task, and overdue-task metrics
- Handoff notes and immutable handoff history
- Controlled rollback to earlier stages
- Required-task, preflight, and automatic review-lock policies
- Approval and unresolved-comment checks before production release
- Automatic migration of Phase 20.0 and 20.1 review data
- Full save/load persistence inside the project model

All workflow behavior is local and functional. No external service or simulated cloud integration is included.
