# Phase 63 - Professional Color Engine 2

Phase 63 adds an application-level professional color pipeline for publishing, vector, raster, typography, layout, screen, and press workflows.

## Included
- RGB, CMYK, and CIE Lab normalization and conversion
- ICC working/proof profile definitions and rendering intents
- Spot colors, tints, alternate process colors, registration and overprint metadata
- Total ink coverage limiting
- Process and spot separation planning
- Soft-proof plans with paper, black-ink, overprint, and gamut-warning simulation
- Global, grouped, locked, and merge-safe swatch libraries
- Delta-E color comparison
- WCAG contrast-ratio calculation
- Color-document preflight and a Phase 63 color plan

## Validation
Run `npm run test:phase63` or `npm run verify:phase63` when dependencies are installed.
