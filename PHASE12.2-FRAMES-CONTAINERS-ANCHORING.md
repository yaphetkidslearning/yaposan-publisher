# Phase 12.2 — Frames, Containers & Anchoring

Phase 12.2 adds a native frame/container model to the real Yaposan editor.

## Included
- Create a padded container frame from any selection
- Parent/child frame membership stored in project files
- Clip-content, preserve-aspect and auto-size settings
- Fit frame to content and fit content to frame
- Page, margin and frame anchoring with persistent offsets
- Detach content, remove frame while retaining content, or delete frame and content
- Frame diagnostics for overflow and orphaned links
- Layout ribbon and Frame Manager integration
- Undo/redo, save/load, locking, layers and export-model compatibility
